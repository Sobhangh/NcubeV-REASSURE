
To run the experiments, the packages listed in the requirements file must be present. Additionally, to use NCubeV it has to be built first and it requries Julia (1.10) to be installed. The build file is in the NCubeV folder.

For running the REASSURE+NCubeV baseline run:
./run_reassure_repair_loop.sh

For running the Supervised repair, run:
./run_supervised_repair_loop.sh
